== IDE

You can use any IDE for this tutorial but if you didn't try it before, we recommend https://code.visualstudio.com/download[VS Code, window="_blank"] with the https://marketplace.visualstudio.com/items?itemName=redhat.java[Language Support for Java(TM) by Red Hat, window="_blank"] and the https://marketplace.visualstudio.com/items?itemName=redhat.vscode-quarkus[Quarkus, window="_blank"] extensions.

[TIP]
====
If you are using vscode then install vscode https://aka.ms/vscode-remote/download/extension[Remote Development Extension pack],
which allows you to run this entire tutorial within a container that will have all tools configured.
====

== CLI Tools

The following CLI tools are required for running the exercises in this tutorial.

////
ifndef::workshop[]
Kubernetes/OpenShift are required only in case you want to deploy the application into them.
endif::workshop[]
////

[WARNING]
====
GraalVM is only required if you intend to build a native image for your local operating system. If you want to create a container using a native image, you can use the Quarkus feature for this and don't need to install GraalVM locally.

Since GraalVM for JDK 17 the `native-image` tool ships with the distribution, so the old
`gu install native-image` step no longer exists — `gu` itself was removed.
====

[NOTE]
====
This revision of the tutorial was validated with *Quarkus 3.39.4* on *Java 21*, *Maven 3.9.11*,
*Podman*, and *OpenShift 4.21* (Kubernetes 1.34). After the first chapter you can use the generated
`./mvnw` wrapper, which downloads its own Maven 3.9.16 and removes the need for a system-wide Maven.
====

The chapters that interact with the cluster also use:

* https://docs.redhat.com/en/documentation/openshift_container_platform/4.21/html/cli_tools/openshift-cli-oc[`oc`, window="_blank"] — the OpenShift CLI. `kubectl` is bundled with it, and the tutorial uses both names.
* https://github.com/rakyll/hey[`hey`, window="_blank"] — a small HTTP load generator, used to put the application under load.
* https://jqlang.github.io/jq/[`jq`, window="_blank"] — used to pretty-print JSON returned by `kubectl -o jsonpath`.
